# Code of conduct

Treat contributors and users with respect. Discuss ideas and code without personal attacks. Harassment, discriminatory language, threats, sexualized conduct, and sharing someone else's private information are not acceptable.

This applies to repository issues, pull requests, discussions, and other project spaces. Keep feedback specific and constructive; assume misunderstandings can be resolved in good faith.

The repository owner, [@maneeshv](https://github.com/maneeshv), may edit or remove inappropriate content and restrict participation. For conduct concerns, contact the owner through a contact method listed on their public profile. If none is available, request a private contact without posting sensitive details. Do not use the security advisory channel for unrelated conduct reports.
